Onde criar API de IA

Links oficiais para gerar a chave de API nos principais provedores de IA. Inclui site, documentação, modelos, free tier e país de origem.

Grátis ≠ licença livre. Aqui “grátis” significa custo zero para usar, com limites. Free tiers mudam sem aviso — confira no site oficial. Origem = país-sede do provedor: empresas chinesas como Alibaba (Qwen) e DeepSeek aparecem como 🇨🇳 China — use o filtro “País” para vê-las. Sem afiliação.
